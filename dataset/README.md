# GoHumanize Open Humanizer Dataset

2000 training pairs and 200 test pairs for teaching a language model to rewrite
AI-styled English prose into natural human writing. Each pair is:

- `input`: a passage rewritten by a large language model in the register typical of LLM output
  (formal, smooth, hedged, connective phrases, no contractions);
- `output`: the original human-written passage from a public-domain book.

The human side is the target. A model trained on this data learns the reverse direction:
from AI-styled prose back to the human original.

Built for the [GoHumanize Open Humanizer](https://gohumanize.ai/research), an educational
open model. It is separate from the production systems of GoHumanize.ai and makes no claim
about AI detectors.

## Sources and licence

All human text comes from **Project Gutenberg** books that are English-language originals
published before 1929, i.e. in the public domain in the United States. Translations were
excluded on purpose (a translation can carry a newer copyright than the original work).
Project Gutenberg boilerplate, footnote markers, illustration tags and typographic artefacts
were stripped; passages are groups of consecutive paragraphs of 80 to 300 words.

The AI-styled inputs were generated by three models with four rotating style prompts:

| Generator | Train rows | Test rows |
|---|---|---|
| meta-llama/llama-3.3-70b-instruct | 504 | 27 |
| deepseek-chat | 487 | 23 |
| gpt-4o-mini | 1009 | 150 |

Dataset licence: **CC-BY 4.0**. Please cite as "GoHumanize team, GoHumanize Open Humanizer
Dataset, 2026".

## Statistics

| | Train | Test |
|---|---|---|
| Rows | 2000 | 200 |
| Books | 47 | 47 |
| Fiction / non-fiction | 1468 / 532 | 142 / 58 |
| Avg. input words | 154.7 | 152.5 |
| Avg. output words | 147.4 | 148.4 |

At most 46 passages per book in training, so no single author dominates. The test split uses
the same books; it measures the transformation, not generalisation to unseen authors.

## How it was built

The full pipeline (sourcing, cleaning, selection, AI-fication, this card) is in
https://github.com/GoHumanize-ai/gohumanize-open-humanizer under `pipeline/`. The write-up
explaining every step is in `docs/paper.md` there.

## Known limitations

- The human prose is old (pre-1929), so the "human" style skews literary and formal-archaic.
- English only. Passages are 80 to 300 words; longer documents are out of scope.
- The AI side reflects three specific generators and four prompts, not all AI writing.
